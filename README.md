# SplitWisee Community Health Files

Repositori `.github` ini menyimpan file *community health* default untuk seluruh repository di organisasi **SplitWisee**.

## File yang disediakan

- `CODE_OF_CONDUCT.md` — pedoman perilaku untuk seluruh kontributor.
- `CONTRIBUTING.md` — panduan kontribusi (issue, branch, commit, pull request, dan review).
- `LICENSE` — lisensi default untuk repository organisasi.

## Cara kerja

GitHub akan menggunakan file-file ini sebagai default pada repository di organisasi yang belum memiliki file sejenis di tingkat repository.

Jika sebuah repository memiliki `README`, `LICENSE`, `CONTRIBUTING`, atau `CODE_OF_CONDUCT` sendiri, maka file lokal repository tersebut akan diprioritaskan.

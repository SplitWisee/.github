# Panduan Kontribusi

Terima kasih telah berkontribusi untuk ekosistem repository **SplitWisee**.

Dokumen ini berlaku sebagai panduan default untuk seluruh repository di organisasi, kecuali jika repository tersebut memiliki `CONTRIBUTING.md` sendiri.

## Cara Berkontribusi

1. Buka issue untuk bug report, pertanyaan, atau usulan fitur.
2. Pastikan issue belum pernah dilaporkan sebelumnya.
3. Jelaskan konteks, langkah reproduksi (untuk bug), dan hasil yang diharapkan.

## Alur Pull Request

1. *Fork* atau buat branch dari default branch repository.
2. Gunakan nama branch yang deskriptif (contoh: `fix/login-timeout`, `feat/export-report`).
3. Lakukan perubahan sekecil mungkin dan fokus pada satu masalah.
4. Jalankan test/lint yang tersedia di repository terkait.
5. Buat pull request dengan deskripsi yang jelas:
   - masalah yang diselesaikan,
   - perubahan utama,
   - cara verifikasi.

## Standar Umum

- Ikuti gaya kode, struktur proyek, dan konvensi yang sudah ada di repository.
- Hindari perubahan besar di luar ruang lingkup issue.
- Pastikan perubahan tidak memasukkan kredensial, token, atau data sensitif.
- Gunakan bahasa yang sopan dan profesional dalam diskusi review.

## Komitmen Kualitas

- Utamakan perubahan yang dapat diuji.
- Tambahkan atau perbarui test jika repository tersebut memiliki infrastruktur test.
- Perbarui dokumentasi bila perilaku sistem berubah.

## Kode Etik

Dengan berpartisipasi, Anda setuju mengikuti [Kode Etik](./CODE_OF_CONDUCT.md) yang berlaku untuk seluruh organisasi SplitWisee.
